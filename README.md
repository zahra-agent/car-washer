# شفرة اتقان — شركة غسيل سيارات بالرياض

موقع حديث وتفاعلي لشركة غسيل وتلميع سيارات بالرياض، مبني بـ Next.js و Tailwind CSS.

## المميزات

- تصميم عصري مع دعم RTL كامل للعربية
- رسوم متحركة تفاعلية (Framer Motion)
- متجاوب مع جميع الأجهزة
- محسّن لمحركات البحث (SEO)
- أزرار تواصل سريعة (واتساب + اتصال)

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## النشر على Vercel

1. ارفع المشروع على GitHub
2. ادخل [vercel.com](https://vercel.com) واربط المستودع
3. Vercel يكتشف Next.js تلقائيًا وينشر الموقع

## التقنيات

- Next.js 16
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide Icons
